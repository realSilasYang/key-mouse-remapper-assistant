# 🎉 键鼠重映射小助手 v0.1.1

## 🚀 优化

- **双版本发行**：正式发布固定为便携版与源码版两个 ZIP。便携版集成当前最新稳定 AutoHotkey，源码版保持完整仓库运行布局，下载用途更加明确。
- **主窗口与托盘**：正常启动静默进入托盘，单击托盘显示主界面；托盘只保留“显示主界面”“重新加载”“退出程序”，重新加载通过一次性交接标记显示新实例。
- **设置与规则包**：设置页“通用”改为“外观”并移除首个 Esc 选项；取消“录制”页签，将导入和导出规则包迁移到独立“规则包”页签。
- **命令栏一致性**：新增、暂停／恢复和删除按钮采用与进程守护小助手一致的固定图标槽；设置、帮助和捐赠按钮提供同款悬浮提示和捐赠交互。
- **事件流性能**：默认不记录或跨进程转发高频鼠标移动事件；只有开启“原始观察”时，包含移动包的完整 Raw Input 才进入 GUI，键盘、鼠标按钮、滚轮和设备事件不受影响。

---

## 🐛 修复

- **事件时间显示**：事件查看器的时间列按 Windows 当前本地时区显示；事件详情和 JSONL 导出继续保留 UTC，避免破坏机器间交换和排序语义。
- **重新加载交接**：退出回调在资源清理后明确允许旧实例退出，避免重新加载时旧进程继续占用单实例锁或主界面无法再次显示。
- **主列表焦点**：点击主窗口空白区域或普通文字后，ListView 完全失焦但当前选中行保持不变。
- **设置窗口布局**：修正设置内容区不对称、字段未居中、长标签裁切，以及规则包页仍显示无关保存区的问题。
- **持久化与资源清理**：持久文件读取加入字节和字符上限，写入保留并发快照和原子替换语义；窗口销毁会聚合报告未完成的回调、子类、图标、GDI 和输入输出清理错误。
