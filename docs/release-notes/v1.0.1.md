# 🎉 键鼠重映射小助手 v1.0.1

## 🚀 优化

- 恢复 Windows GitHub Actions 持续集成，复用经过校验的固定工具链与字体资源，并在 `main` 变更时完整验证界面、便携包和源码包，确保正式发布物继续通过同一套发行门禁。
- 13 种语言 README 现在并排展示深色与浅色主界面，下载前即可直接比较两种主题的实际效果。

---

## 🐛 修复

- 启动时通过隐藏后重新显示托盘图标触发再次注册，规避 Explorer 通知区域尚未就绪时的竞争，修复小助手已经运行但托盘图标偶发缺失的问题。
- 比较快捷方式目标时统一展开 Windows 8.3 短路径，避免同一入口因长短路径写法不同而被误判，减少桌面和开始菜单快捷方式的不必要重建或校验失败。

---

## 📦 发布物说明

- **`key-mouse-remapper-assistant-1.0.1-source.zip`（完整源码版）**：包含可运行 AHK 源码、应用模块、资源、13 语 README、双语更新日志、测试和构建工具，适合审阅、开发或从源码运行；本机需要 AutoHotkey v2 x64。
- **`key-mouse-remapper-assistant-1.0.1-windows-x64.zip`（完整便携版，推荐）**：包含编译 EXE、可编辑映射源码、13 语 README、双语更新日志、许可证、应用模块、界面资源、固定 AutoHotkey v2.0.26 x64 运行时及对应源码归档；无需另行安装 AutoHotkey，适合完整解压后长期使用。
