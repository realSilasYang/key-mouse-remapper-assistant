# 🎉 键鼠重映射小助手 v1.0.1

## ⚠️ 重要说明

- **字体加载方式变更**：程序包不再内含或私有加载字体；需要 Noto 回退字体显示效果时，必须下载可选字体包并安装到 Windows。

---

## 🚀 优化

- 恢复 Windows GitHub Actions 持续集成，复用经过校验的固定工具链与字体资源，并在 `main` 变更时完整验证界面、便携包和源码包，确保正式发布物继续通过同一套发行门禁。
- 13 种语言 README 现在逐行展示深色与浅色主界面，下载前即可清晰查看两种主题的实际效果。
- 运行时只按原有优先级选择 Windows 已安装字体；源码包和便携包不再包含字体，CI 与发行构建统一从独立 `fonts.zip` 恢复和交付字体资源。

---

## 🐛 修复

- 启动时通过隐藏后重新显示托盘图标触发再次注册，规避 Explorer 通知区域尚未就绪时的竞争，修复小助手已经运行但托盘图标偶发缺失的问题。
- 比较快捷方式目标时统一展开 Windows 8.3 短路径，避免同一入口因长短路径写法不同而被误判，减少桌面和开始菜单快捷方式的不必要重建或校验失败。

---

## 📦 发布物说明

- **`fonts.zip`（可选字体包）**：提供 Noto 回退界面字体，需先安装到 Windows；它不是程序运行必需。
- **`key-mouse-remapper-assistant-1.0.1-source.zip`（完整源码版）**：包含可运行 AHK 源码、应用模块、除字体外的资源、13 语 README、双语更新日志、测试和构建工具，适合审阅、开发或从源码运行；本机需要 AutoHotkey v2 x64。
- **`key-mouse-remapper-assistant-1.0.1-windows-x64.zip`（完整便携版，推荐）**：包含编译 EXE、可编辑映射源码、13 语 README、双语更新日志、许可证、应用模块、除字体外的界面资源、固定 AutoHotkey v2.0.26 x64 运行时及对应源码归档；无需另行安装 AutoHotkey，适合完整解压后长期使用。
