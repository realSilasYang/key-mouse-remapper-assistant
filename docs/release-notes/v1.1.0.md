# 🎉 键鼠重映射小助手 v1.1.0 - 2026-09-25

## ✨ 新增

- 集成 Interception x64：支持应用内检测与安装、卸载驱动、录制来源设备，并通过 `from.device` 创建指定物理设备的映射。未匹配的输入会原样回送。安装或卸载驱动均需要管理员权限和重启 Windows；普通规则无需驱动。
- 新建简易规则可让目标按键留空，保存为 `block=true` 的来源按键屏蔽规则。

---

## 🚀 优化

- 单键目标随来源键成对按下和释放，可参与后续 Ctrl、Shift、Alt、Win 组合。关闭“区分左/右侧修饰键”时，同时识别来源键的左右侧，目标修饰键统一使用左侧。
- 调整新建简易规则按钮、设备区分与修饰键选项的布局和配色；改善生效范围列、窗口缩放后的控件显示，以及屏幕边缘的悬停提示。
- 驱动状态为“已就绪”时，设置页的操作按钮变为“卸载驱动”，确认后请求管理员权限执行卸载；卸载按钮采用更深红色，提高白色文字在深色界面上的可读性。
- AI 规则生成与优化加入 Interception 设备编号及驱动前置条件信息。

---

## 🐛 修复

- 改善按键录制超时停止与输入清理；来源键保持按下时不会因修饰键变化切换规则或再次触发单次动作。
- 改善驱动缺失提示、设备规则批量暂停与恢复，以及窗口大小变化后的列表绘制。

---

## 📦 发布物说明

源码包和便携包不包含字体；字体只通过下面的可选独立附件提供。

- **`fonts.zip`（可选字体包）**：提供 Noto 回退界面字体，需先安装到 Windows；它不是程序运行必需。
- **`key-mouse-remapper-assistant-1.1.0-source.zip`（完整源码版）**：包含可运行 AHK 源码、应用模块、除字体外的资源、13 语 README、双语更新日志、测试和构建工具，适合审阅、开发或从源码运行；本机需要 AutoHotkey v2 x64。
- **`key-mouse-remapper-assistant-1.1.0-windows-x64.zip`（完整便携版，推荐）**：包含编译 EXE、可编辑映射源码、13 语 README、双语更新日志、许可证、应用模块、除字体外的界面资源、固定 AutoHotkey v2.0.26 x64 运行时及对应源码归档；无需另行安装 AutoHotkey，适合完整解压后长期使用。
