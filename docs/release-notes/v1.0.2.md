# 🎉 键鼠重映射小助手 v1.0.2

## ✨ 新增

- 显示设置新增 100%、110%、125%、150%、175% 和 200% 界面缩放，可统一放大主窗口、编辑器、设置及其他辅助窗口的文字和控件。
- AI 优化结果应用后支持 `Ctrl+Z` 恢复优化前内容，并可用 `Ctrl+Shift+Z` 重做。

---

## 🚀 优化

- 统一增大过小字号并同步调整各窗口布局；主界面录制区采用更紧凑的名称输入框、等宽的保存与清空按钮，以及独立的全宽状态区域。
- AI 生成、优化、修复和复核链路现在会获得更完整的规则块能力、AHK v2 运行环境、输入时序、受托管生命周期和本地校验反馈；生成的受托管脚本需要包含准确的详细注释。
- AI 连接测试只使用窗口中的临时参数，所有设置都只在点击“保存”后写入。
- 更新 13 种语言 README 中的深色和浅色界面概览，使文档与当前主界面一致。

---

## 🐛 修复

- 修复子窗口滚轮消息透传到上一级窗口、导致后方主界面同时滚动的问题。
- 修复主列表未选中条目时 `Ctrl+N` 无法新增规则，以及录制期间点击“清空”会误录鼠标左键的问题。
- 修复新增或编辑规则后的长状态文本在窗口缩放、主题刷新和动态布局中被截断、重叠或留下按钮残影的问题。
- 修复自定义界面缩放下控件重复缩放、字体测量、圆角按钮、列表列宽、弹窗区域和窗口最小尺寸不一致的问题。
- 恢复完整的 18 条内置规则，并重新启用发布构建中的精确数量检查。

---

## 📦 发布物说明

源码包和便携包不包含字体；字体只通过下面的可选独立附件提供。

- **`fonts.zip`（可选字体包）**：提供 Noto 回退界面字体，需先安装到 Windows；它不是程序运行必需。
- **`key-mouse-remapper-assistant-1.0.2-source.zip`（完整源码版）**：包含可运行 AHK 源码、应用模块、除字体外的资源、13 语 README、双语更新日志、测试和构建工具，适合审阅、开发或从源码运行；本机需要 AutoHotkey v2 x64。
- **`key-mouse-remapper-assistant-1.0.2-windows-x64.zip`（完整便携版，推荐）**：包含编译 EXE、可编辑映射源码、13 语 README、双语更新日志、许可证、应用模块、除字体外的界面资源、固定 AutoHotkey v2.0.26 x64 运行时及对应源码归档；无需另行安装 AutoHotkey，适合完整解压后长期使用。
