# 🎉 键鼠重映射小助手 v0.1.0

## ✨ 新增

- **实体设备映射**：输入链路统一使用 Windows Raw Input，可区分事件来自哪一把实体键盘或哪一只实体鼠标；录制来源输入时会绑定首个产生事件的设备 `stable_id`。
- **托管规则运行时**：生产规则使用 RuleSpec v2 描述按键、鼠标、修饰键、长按、重复、同时键、序列、计时、窗口和应用条件；映射区域只保存托管注释块，不执行规则包或用户写入的 AHK 代码。
- **设备隔离状态**：修饰键、按住、重复、组合、序列、计时和合成输出所有权均按设备隔离；设备移除、重绑、系统唤醒、规则热应用、挂起和退出会释放对应状态与输出。
- **受监督输入进程**：GUI 默认通过认证命名管道监督唯一的无托盘 `input-worker`；CLI 修改规则后通知运行中的 GUI 热应用，无需重载输入实现。
- **规则包与诊断**：支持 managed RuleSpec 规则包导入、冲突预览、导出和完整性校验，并提供设备、能力、模拟、诊断包与事件记录入口。

## 🚀 优化

- **产品标识与数据迁移**：中文名统一为“键鼠重映射小助手”，英文名统一为 “Keyboard & Mouse Remapper Assistant”，代码、入口、图标、GitHub、CI 和发行物统一使用 `KeyMouseRemapperAssistant`／`key-mouse-remapper-assistant`；默认数据目录迁移到 `%APPDATA%\KeyMouseRemapperAssistant`，兼容迁移旧名称数据且不覆盖已有目标文件。
- **输入能力边界**：明确 Raw Input 只识别实体设备并产生附加输出，不安装驱动、低级钩子或系统服务，也不宣称抑制、替换或隐藏 Windows 原输入。
- **主窗口与托盘**：正常启动静默进入托盘，单击托盘显示主界面；托盘只保留“显示主界面”“重新加载”“退出程序”，重新加载通过一次性标记让新实例显示主界面。
- **设置与规则包**：设置页“通用”改为“外观”并移除首个 Esc 选项；取消“录制”页签，将导入和导出规则包迁移到独立“规则包”页签。
- **命令栏一致性**：新增、暂停／恢复和删除按钮采用与进程守护小助手一致的固定图标槽；设置、帮助和捐赠按钮提供同款悬浮提示，捐赠文案与交互保持一致。
- **窗口与主题一致性**：自绘按钮恢复 Windows 无障碍按钮语义，主工具栏和外链按钮使用延迟、无激活、DPI 感知的深浅色提示；子窗口最小化、Owner、模态、图标、GDI、消息回调和计时器均由明确所有者管理。
- **字体与本地化**：公开发行只包含 OFL 许可的 Noto 界面字体，CJK 字体集合精简为五个地区 Regular 字体面；CLI 标准输出固定为无 BOM UTF-8，构建和验证兼容 Windows PowerShell 5.1 与 PowerShell 7。
- **可复现发行**：发行 manifest 固定声明 `inputBackend: raw-input`、`requiresDriver: false` 和 `suppressesOriginalInput: false`，锁定工具链、运行时摘要、ZIP 内容和第三方许可均进入自动验证。

## 🐛 修复

- **重新加载交接**：退出回调在资源清理后明确允许旧实例退出，避免重新加载时旧进程仍占用单实例锁或主界面无法再次显示。
- **主列表焦点**：点击主窗口空白区域或普通文字后，键盘焦点转移到不可交互的状态文字，ListView 完全失焦但当前选中行保持不变。
- **设置窗口布局**：移除主界面重复的事件查看器入口，修正设置内容区不对称、字段未居中、长标签裁切，以及规则包页仍显示无关保存区的问题。
- **持久化与资源清理**：持久文件读取加入字节和字符上限，写入保留并发快照和原子替换语义；窗口销毁会聚合报告未完成的回调、子类、图标、GDI 和输入输出清理错误。
