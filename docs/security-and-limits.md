# 安全和限制

## 权限

程序以当前普通用户运行，不安装服务，不加载内核组件，也不要求管理员权限。它不能观察
安全桌面、登录前桌面或其他用户会话中的输入，也不能绕过 UIPI、受保护进程、反作弊或
企业安全策略。

## Raw Input 边界

Raw Input 可以把键盘和鼠标事件归属到设备，但不能取消已经发给 Windows 的原输入。
因此本项目只做附加输出：物理键本身仍会照常到达前台应用。需要阻止、替换或隐藏物理输入
的场景不在范围内。

Raw Input 设备接口路径可能在换 USB 端口、固件变化、设备重装或系统更新后改变。
`stable_id` 尽力用容器和接口信息稳定标识，但规则仍应在硬件变化后重新确认。

## 规则安全

- 映射区域只允许注释和空行。
- 只接受 managed RuleSpec；不执行导入包携带的 AHK 代码。
- JSON、规则数、条件深度、动作数量、字符串和文件都有资源上限。
- 规则块和规则包使用 SHA-256 检查意外损坏；SHA-256 不是来源签名。
- `run` 动作需要运行时安全策略允许，规则包会声明 `execute_process` 权限。
- `window_close`、`window_minimize` 和 `lock_workstation` 会影响当前桌面状态，应只绑定明确
  的来源和条件。

## 输出恢复

合成按下由 `OutputLedger` 按 owner 追踪。正常释放、设备移除、规则热应用、挂起和退出都
会释放活动 owner。恢复日志用于处理上次进程异常结束留下的合成按键；它不会发送未登记的
鼠标按钮抬起。

操作系统、目标应用或第三方输入软件仍可能在进程崩溃瞬间看到不完整组合。不要把本项目
用于安全关键、医疗、工业控制或必须保证实时释放的用途。

## IPC 和文件

worker 管道限制为当前用户，并验证 PID、SID、会话密钥、HMAC 与单调序号。启动环境通过
一次性 DPAPI 文件传递。所有持久文件仍受当前用户账户和目录 ACL 控制；拥有同等账户权限
的进程可以修改它们。

仓储写入会拒绝并发快照变化，但不是通用版本控制系统。重要规则应纳入 Git 或单独备份。

## 不支持

- 抑制或替换原始物理输入；
- 登录界面、安全桌面、其他会话和远程内核级输入；
- 32 位 Windows、Windows 7、macOS 或 Linux；
- 将设备枚举当作设备实际独立输入的证明；
- 对第三方键盘固件、厂商软件和远程桌面行为作统一保证。
