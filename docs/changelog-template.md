# 📝 中文更新日志模板

**简体中文** | [English](en/changelog-template.md)

新增版本时，把下面的版本块复制到根目录 `CHANGELOG.md` 的“未发布”内容下方，
再把已经发布的条目移入该版本。发布物说明必须保留；其余只保留本次实际包含的分类。
模板默认不生成“重要说明”，只有存在破坏性变化或用户必须执行的升级操作时才手动加入。

```markdown
## 🎉 版本 [X.Y.Z] - YYYY-MM-DD

### 📦 发布物说明

- **`key-mouse-remapper-assistant-X.Y.Z-windows-x64.zip`（完整便携版，推荐）**：包含已编译 EXE、AutoHotkey 最新稳定版 x64 运行时、GUI 与 PowerShell CLI、运行模块、文档、字体和许可证；无需另行安装 AutoHotkey，完整解压后即可运行。
- **`key-mouse-remapper-assistant-X.Y.Z-source.zip`（完整源码版）**：包含 AHK 源码、CLI、模块、测试、构建工具、GitHub 工作流、文档和资源，适合审阅、开发或自行构建；不包含编译 EXE 和便携运行时。

---

### ✨ 新增

- **功能名称**：说明新增了什么、适用于什么输入设备或映射场景，以及用户可以获得什么。

---

### 🚀 优化

- **功能名称**：说明原有体验或行为如何改变，以及用户能够观察到的具体结果。

---

### 🐛 修复

- **问题名称**：说明原先会出现什么问题，以及修复后的正确行为。

---

### 🔒 安全

- **问题名称**：只在安全修复已经可以公开时保留，说明受影响版本、修复版本和用户是否需要立即操作；不要披露可直接利用的细节。
```

## 📐 编写规则

- 文档标题固定使用 `📋 更新日志`，版本标题固定使用 `🎉 版本 [X.Y.Z] - YYYY-MM-DD`。版本号必须与 `VERSION`、主脚本 Ahk2Exe 文件版本和 Git 标签一致。
- 每个正式版本必须包含 `📦 发布物说明`，并且只列出工作流实际上传的便携 ZIP 和源码 ZIP，包括准确文件名、包含内容、AutoHotkey 要求和适用场景；不得写入独立 EXE、`SHA256SUMS.txt` 或其他未发布资产。
- `⚠️ 重要说明` 是可选警告章节，默认不生成。只有现有数据或规则不兼容、可能丢失数据、最低环境或权限发生破坏性变化、默认行为带来升级风险，或者用户必须在升级前后迁移、备份或完整替换文件时才加入。
- 不得把“配置保持兼容”“可直接升级”、下载建议、发行物选择、功能简介、一般使用建议或验证范围写进 `⚠️ 重要说明`。若存在该章节，每项必须写清受影响对象、具体风险和必要操作，并置于常规分类之前；没有合格事项时连标题一起删除。
- 常规分类固定使用 `✨ 新增`、`🚀 优化`、`🐛 修复`；没有内容的分类直接删除。`🔒 安全` 仅在协调披露后使用。
- 更新日志和 Release Notes 均不得包含“✅ 验证范围”章节，也不得罗列测试数量、构建哈希或尚未完成的人工矩阵。验证结果统一保存在验证证据、CI／Release Actions 日志和完整构建产物中。
- 每项先用粗体短语概括功能或问题，再用完整中文说明用户可见变化、适用范围和收益。
- 合并同一功能的零散提交，不直接罗列提交标题、文件名、内部类名、变量名或纯重构过程。内部变化只有在影响可靠性、性能、兼容性或维护边界时写入。
- 配置格式、RuleSpec、规则包、默认值、权限、输入边界、设备绑定和最低环境发生变化时，必须说明旧数据如何处理、是否需要备份，以及失败后怎样恢复。
- GUI、DPI、暗色模式、多显示器或实体设备变化只描述实际完成的范围；未经真实设备验证的组合必须留在人工回归矩阵中，不能写成已经全面支持。
- `CHANGELOG.md` 中的发布物说明放在每个版本开头；`docs/release-notes/v<版本>.md` 中的发布物说明必须是最后一个二级章节，便于读完变化后直接选择下载。
- 发布版本后更新文件末尾的比较链接：`[未发布]` 指向最新标签到 `HEAD`，版本链接指向对应 GitHub Release。

## 发布前示例

```markdown
## 🚧 [未发布]

### 🚀 优化

- **问题反馈流程**：缺陷表单现在收集 Windows、显示缩放、实体设备、映射类型和运行上下文，减少因环境信息不足造成的往返确认。

## 🎉 版本 [0.1.1] - YYYY-MM-DD

### 📦 发布物说明

- **`key-mouse-remapper-assistant-0.1.1-windows-x64.zip`（完整便携版，推荐）**：包含已编译 EXE、AutoHotkey 最新稳定版 x64 运行时、CLI、运行模块、文档、字体和许可证；无需另行安装 AutoHotkey，完整解压后运行。
- **`key-mouse-remapper-assistant-0.1.1-source.zip`（完整源码版）**：包含 AHK 源码、CLI、模块、测试、构建工具、GitHub 工作流、文档和资源；不包含编译 EXE 和便携运行时。

---

### 🐛 修复

- **空白区域焦点**：点击主窗口空白区域后，主列表不再继续接收键盘操作，当前选择仍会保留。
```
